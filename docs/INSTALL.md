# Installation

1. Download the latest release package.
2. Open Thunderbird.
3. Open Add-ons and Themes.
4. Use the gear menu to install an add-on from a local file.
5. Select the downloaded package.
6. Restart Thunderbird if requested.

## Compatibility

Version 1.0.11 supports Thunderbird 152.* through 160.*. Version 1.0.10 supports through Thunderbird 159.*.
