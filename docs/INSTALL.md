# Installation

1. Download the latest release package.
2. Open Thunderbird.
3. Open Add-ons and Themes.
4. Use the gear menu to install an add-on from a local file.
5. Select the downloaded package.
6. Restart Thunderbird if requested.

## Compatibility

Thunderbird 152 or later. Each new Thunderbird version is reviewed during its beta; if it requires changes, a new TN Thread Order version is published.
